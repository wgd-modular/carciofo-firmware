# Quattro

Four effects in one Carciofo, always live and always in the same order:

```
drive -> chorus -> delay -> reverb
```

Each pot owns one effect. What changes is not which pot does what, but which of
that effect's parameters the pot reaches, and that is what the two buttons are
for. They are shift keys, not switches. Hold one to peel back a layer.

## Layers

| Layer | How | P1 Drive | P2 Chorus | P3 Delay | P4 Reverb |
|-------|-----|----------|-----------|----------|-----------|
| Character | no button | drive | rate | time | size |
| Motion | hold B1 | tone | depth | feedback | tone |
| Mix | hold B2 | wet | wet | wet | wet |

Every effect crossfades its own wet against the signal that reaches it, so a
mix at zero is a real bypass and all four mixes down is a clean thru. Out of the
box the mix layer sits on a gentle stock patch, a little chorus and delay under
a soft reverb, drive off, so there is something to hear before you touch it.

If both buttons are held, B2 wins.

## Soft pickup

Because a pot means three different things, shifting a layer leaves it parked
away from the value stored underneath. Rather than jump, a pot stays quiet until
you turn it back through that stored value, then it takes hold. Nothing steps.
The LED tells you which pot is still being hunted for and blips white the moment
it lands.

## CV

| Input | Rides |
|-------|-------|
| CV1 | delay time |
| CV2 | reverb size |

Both sit on top of their pot and stay live no matter which layer you are on, so
you can keep a hand on the character controls and still sweep them from a patch.

## LED

One light doing a lot of work.

- **Turning a pot** shows that effect's colour, drive red, chorus green, delay
  blue, reverb violet, with the brightness on the value. The layer restyles it:
  the motion layer breathes, the mix layer washes toward white.
- **A pot still being picked up** blinks until it catches, then throws a short
  white blip.
- **Holding a button** with nothing turning yet just marks the armed layer,
  motion breathing, mix steady, both near white so no effect colour is implied.
- **Idle** it settles into the patch as a single colour, each effect weighted by
  how wet it is, breathing on the total. A clean thru keeps a faint pulse.

## Controls

| Control | Function |
|---------|----------|
| P1 | Drive: amount / tone / wet |
| P2 | Chorus: rate / depth / wet |
| P3 | Delay: time / feedback / wet |
| P4 | Reverb: size / tone / wet |
| CV1 | Delay time |
| CV2 | Reverb size |
| B1 | Hold for the motion layer |
| B2 | Hold for the mix layer |
