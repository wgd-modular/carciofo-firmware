# Reverb

## Description

Stereo reverb with a freeze and an octave up shimmer.

| Control | Function      |
|---------|---------------|
| P1      | Dry Level     |
| P2      | Wet Level     |
| P3      | Decay         |
| P4      | Tone          |
| CV1     | Decay CV      |
| CV2     | Tone CV       |
| B1      | Freeze        |
| B2      | Shimmer       |

Both buttons latch, press again to leave.

Freeze mutes the send into the tank and takes the feedback to unity, so whatever is in there at that moment holds. Shimmer folds an octave up copy of the tank output back into its own input. The decay range gets pulled in a little while the shimmer is on, the octave path adds gain of its own and the tank has to give some back for the loop to settle instead of running away.

The LED sits on the decay, cyan into violet while the reverb is plain and yellow into red once the shimmer is in. Brightness follows the wet level. A frozen tail overrides all of that with a slow white breath.
